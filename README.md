# Should we expand to Brazil?

An analysis of the Brazilian market in 2017 to determine whether it was ready for high-priced Apple products and whether working with Magist would be a suitable option.

## Project Overview

The goal of this project was to analyze a database and develop a recommendation for a potential market expansion.

We investigated two main questions:

Was the Brazilian market in 2017 ready for high-priced Apple products?
Should we work with Magist as a potential partner?

The analysis was based on sales, customer, product, and order data from the Brazilian market.

## Dataset

- 1 Database  
- 9 Tables
- Brazilian e-commerce data from 2017

## Technologies

- MySQL - Data analysis and SQL queries
- Tableau - Data visualization
- Google Slides - Final presentation
